# Even Reader — Читалка книг и формул для Even Realities G2

Полноценная читалка для умных очков **Even Realities G2**. Позволяет комфортно читать художественный текст, технические конспекты и сложные математические формулы LaTeX (`\sqrt{}`, многоэтажные дроби, интегралы, степени, матрицы) прямо на линзах очков.

Изображение формируется под зеленый монохромный Micro-LED дисплей очков с разрешением **576×288** (сетка 2×2 из тайлов 288×144). Текст плотно заполняет экран от края до края без дыр, а главные формулы автоматически центрируются по середине.

---

## 🚀 Как запустить читалку на очках

Есть два простых варианта: постоянная установка на очки навсегда или быстрый тест за 1 минуту по Wi-Fi.

### Вариант 1. Установка на очки навсегда (Рекомендуется)
*Готовый файл `even-reader.ehpk` уже лежит в папке проекта. Для личного использования никаких платных аккаунтов, одобрений или проверок ждать не нужно — всё ставится сразу.*

1. Зайдите на портал разработчиков [hub.evenrealities.com](https://hub.evenrealities.com) и войдите под своей обычной учетной записью от приложения Even (доступ разработчика дается автоматически и бесплатно).
2. Откройте терминал в папке проекта и выполните вход:
   ```bash
   npx evenhub login
   ```
   *(Введите email и пароль от аккаунта Even)*.
3. Загрузите готовый пакет в свой профиль:
   ```bash
   npx evenhub create even-reader.ehpk --name "Even Reader" --tagline "Math & Book Reader"
   ```
4. Откройте приложение **Even Realities** на телефоне:
   - Перейдите в раздел **Even Hub** (или вкладку профиля → *Developer Builds / My Apps*).
   - Найдите приложение **Even Reader** и нажмите кнопку **Install**.
5. Приложение запишется в память очков по Bluetooth. Всё готово! Теперь компьютер не нужен — читалка всегда с вами и работает 100% оффлайн в любом месте.

---

### Вариант 2. Быстрый запуск по Wi-Fi (без регистрации за 1 минуту)
*Удобно, если нужно прямо сейчас надеть очки и посмотреть, как это выглядит вживую.*

1. В приложении Even на смартфоне откройте **Настройки (Settings) → О приложении (About)** и нажмите **7 раз подряд** по номеру версии — включится режим разработчика (*Developer Mode*).
2. Запустите сервер читалки на компьютере:
   ```bash
   npm run dev
   ```
3. В приложении Even на телефоне нажмите **Scan QR** и наведите камеру на экран компьютера с терминалом.
4. Читалка мгновенно отобразится на линзах ваших очков.

## 📖 Как готовить и загружать свои книги (.evr)

Очки Even G2 имеют слабый микроконтроллер, поэтому тяжелый расчет шрифтов и верстки выполняется заранее на ПК в нашем конвертере:

1. Запустите программу **`EvenReaderConverter.exe`** (или `python EvenReaderConverter.py`).
2. Вставьте свой текст, напишите формулы в LaTeX (например, `\sqrt{x}`, `\frac{a}{b}`, `$$E=mc^2$$`) или нажмите **«Импорт файла»** для загрузки своего PDF, TXT или Markdown.
3. В правом окне программы сразу появится живой предпросмотр: вы увидите в точности то, как экраны отобразятся на очках.
4. Нажмите кнопку **«Сохранить .EVR»**.
5. Перекиньте полученный `.evr` файл на телефон (через Telegram, AirDrop или провод) и выберите его в читалке Even Reader.

## 🎮 Управление при чтении

Листать экраны можно прямо на очках сенсорной дужкой или кольцом Even R1:
- **Свайп вперед по правой дужке** — следующий экран книги.
- **Свайп назад по правой дужке** — предыдущий экран книги.
- **Одиночный тап** — показать статусную строку и текущий номер страницы.
- **Двойной тап** — вернуться в меню библиотеки.

## 🛠️ Для разработчиков: сборка из исходников

Если вы хотите изменить интерфейс, добавить свои функции и пересобрать `.ehpk` самостоятельно:

```bash
# 1. Установка зависимостей
npm install

# 2. Проверка типов и сборка бандла
npm run build

# 3. Упаковка в официальный установочный пакет .ehpk
npm run pack
```

После этого в папке обновится готовый файл `even-reader.ehpk`.

### Запуск в официальном симуляторе на ПК (без очков):
```bash
# Терминал 1: запуск сервера
npm run dev

# Терминал 2: запуск окна симулятора очков
npx evenhub-simulator http://localhost:5173
```
