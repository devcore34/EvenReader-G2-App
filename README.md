# Even Reader — Приложение для AR-очков Even Realities G2

Полноценная читалка книг формата `.evr` (математика, LaTeX, формулы, техническая литература) прямо на монохромном Micro-LED дисплее очков Even Realities G2 (разрешение 576×288, сетка 2×2 из тайлов 288×144).

---

## ⚡ 1. Быстрый запуск БЕЗ СБОРКИ (Ready-to-Use)

В этой папке уже лежит готовый скомпилированный пакет:
👉 **`even-reader.ehpk`**

### Как установить его на свои очки:
1. Зарегистрируйтесь на портале разработчика: [developer.evenrealities.com](https://developer.evenrealities.com) (бесплатно под вашим аккаунтом Even).
2. В терминале выполните вход:
   ```bash
   npx evenhub login
   ```
3. Загрузите пакет в свой аккаунт:
   ```bash
   npx evenhub create even-reader.ehpk --name "Even Reader" --tagline "Math & Book Reader for G2"
   ```
4. Откройте приложение **Even Realities** на телефоне: в разделе **Even Hub → My Apps / Developer** появится приложение. Нажмите **«Install»** — читалка установится прямо в очки!

---

## 🛠️ 2. Сборка из исходников (Build from Source)

Если вы хотите изменить код, добавить свои функции или пересобрать приложение:

### Требования:
- Node.js 20+ или 22+

### Шаги сборки:
```bash
# 1. Установка зависимостей
npm install

# 2. Проверка типов и сборка веб-бандла
npm run build

# 3. Упаковка в официальный файл .ehpk
npm run pack
```
После этого будет создан свежий файл `even-reader.ehpk`.

---

## 💻 3. Запуск и тестирование в симуляторе на ПК

Чтобы протестировать работу читалки на компьютере без физических очков:

**Терминал 1 (запуск локального сервера):**
```bash
npm run dev
```

**Терминал 2 (запуск симулятора очков Even Realities):**
```bash
npx evenhub-simulator http://localhost:5173
```

## 🎮 Управление на очках (сенсорная дужка / кольцо Even R1)
- **Свайп вперед (Scroll Down)**: следующий экран книги
- **Свайп назад (Scroll Up)**: предыдущий экран книги
- **Одиночный клик**: строка состояния / прогресс чтения
- **Двойной клик**: выход в библиотеку книг
